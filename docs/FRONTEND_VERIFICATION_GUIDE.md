> 本文档提供在有 Node.js 环境时进行前端验证的步骤

## 快速验证步骤

### 1. 安装依赖

```bash
cd web
npm install
```

### 2. 构建检查

```bash
npm run build
```

预期结果：
- 构建成功，无 TypeScript 错误
- 无 ESLint 错误
- 输出到 `.next` 目录

### 3. 开发服务器

```bash
npm run dev
```

访问 http://localhost:3000

## 常见问题排查

### 1. 构建失败

**问题**：TypeScript 类型错误

**解决**：
```bash
# 检查类型错误
npx tsc --noEmit

# 检查 ESLint 错误
npm run lint
```

### 2. WebSocket 连接失败

**问题**：无法连接到后端 WebSocket

**解决**：
- 确认后端服务运行在 http://localhost:8000
- 检查 `.env` 文件中的 `NEXT_PUBLIC_WS_BASE_URL`
- 检查浏览器控制台的网络错误

### 3. 样式问题

**问题**：样式不生效或显示异常

**解决**：
- 清除 `.next` 目录重新构建
- 检查浏览器是否支持 CSS 变量
- 检查 `globals.css` 是否正确导入

### 4. 移动端布局问题

**问题**：出现横向滚动或元素溢出

**解决**：
- 使用 Chrome DevTools 的 "Show rulers" 功能
- 检查是否有固定宽度的元素
- 确认所有文本容器都有 `overflow-wrap` 或 `word-break`
